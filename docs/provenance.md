# Code and asset provenance

Paper was coded entirely with AI tools at its creator's direction. The origin
of every generated line has not been independently established. Neither the
MIT license nor this disclosure grants rights in material belonging to others.

## Review for the first public alpha

The release starts from an explicit source-file export of the private application.
Private Git history, environment files, databases, feed exports, and operational
records are excluded. Personal defaults are replaced with configurable values.

The production dependency inventory uses the locked package versions and copies
the license files distributed with them. The saxes 6.0.0 package omits its license
file, so its ISC notice was retrieved from that upstream release. Its source and
hash are recorded under licenses/supplemental/saxes.

The original inline icons resembled an existing icon set. All 20 were replaced
with SVG geometry from Feather 4.29.2, pinned to commit
1b002399e8758fb2bccea4d07312dc9e0f43dcb8. The MIT license, source paths, and hashes
are under licenses/feather. This gives these assets a documented source.

Fonts come from the locked Fontsource packages and retain their OFL-1.1 notices.
Existing Paper logos and application icons are retained as project branding.
Their original creation process has not been independently verified.

The tools and provider terms for all historical generated code are not fully
recorded. Rights in their historical output have not been independently verified.
Source headers and attribution markers were checked. A redacted Gitleaks 8.30.1
scan of the public source snapshot reported no secret findings. This is a limited review,
not an exhaustive code-similarity audit, an ownership determination, or a
guarantee of noninfringement. No dependency inventory can establish the origin
of all application code. No live AI account is used to test the public release.

## Reporting an attribution problem

Open an issue identifying the file, the suspected original source, and its
license. Do not submit credentials or private feed contents. Specific reports
can be investigated and the affected material attributed, replaced, or removed.

Keep third-party notices when contributing copied or adapted material. Identify
the source of code and assets you bring into the project, including material
produced with an AI tool that identifies an upstream match.
